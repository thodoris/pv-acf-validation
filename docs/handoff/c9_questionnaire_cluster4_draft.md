## Orientation for the reviewer of this draft

This is the fourth and last of the four claim-clusters. Cluster 1 established **the problem** — the governance gap, where it sits, whether existing arrangements cover it, whether generative LLMs change it. Cluster 2 turned to **the framework** as the proposed response. Cluster 3 went down one level, to **the four selected instruments as operational objects**. Cluster 4 is **the close** — a single open-only catch-all that lets the respondent set the agenda before the questionnaire ends. The cluster grouping is not a part-count commitment; Cluster 1's orientation states the standing position and it is not relitigated here.

**Cluster 4 covers the close.** Its job: give the respondent one unbounded place to raise anything the structured questions did not reach — a concern, a gap, a strength the questions overlooked, a question the instrument should have asked. The construct memo's Block 3 (§3.3) specifies "one or two final open items soliciting additional concerns, gaps, or critiques not covered by the structured questions"; Cluster 4 carries the one obligatory item, with a second optional item held as an open decision (see the notes).

**One screen, one question.** Cluster 4 is a single screen carrying a single question. There is no object to present and no instrument to put in view — only the closing invitation. It is the lightest screen in the questionnaire by design: the closing cluster's job was always lighter than the other three, and one well-placed catch-all does it.

**What Cluster 4 deliberately does not carry — and the consequence for Chapter 9.** An earlier draft of this cluster carried a second question probing the framework's self-limitation discipline (construct C5'). It was dropped: C5' is reserved for interview deepening, which the construct memo already anticipates (§3.1 — "Reserved for interview probing where the deepening exchange can surface specific mechanism-level engagement"). The consequence is that **C5' is probed nowhere in the questionnaire.** Under the hybrid outcome this is by design — the interview carries it. Under the questionnaire-only fallback, C5' is not probed by the expert component at all (construct memo §3.1: "If fallback obtains, C5' is not probed at the expert-component level; the framework's self-limitation discipline is discussed in Chapter 9 through the retrospective application only"). This is in line with the spec, not a deviation — but Chapter 9's expert-component framing should name it, so the dual-framing accounts for which constructs the questionnaire covers under each outcome. The visibility-not-solutions rationale was already put to the respondent once, at Cluster 1 Q1.6, so the questionnaire is not silent on the framework's self-limiting orientation; it is only silent on the C5' mechanism-level probe.

**Each question carries the eight-element template locked with Cluster 1:**
- **The question** — practitioner-facing, plain, short. The primary element in the reading path.
- **Subtitle (scope note)** — a syntactically complete sentence or two, in the reading path immediately under the question, that bounds what the question means and what a good answer attends to (UI spec P5). It carries scope, not rationale, and it does not double as the open prompt.
- **Type** — `open-only` / `rating-only` / `rating + required open` / `rating + optional open`. Cluster 4's one question is `open-only`.
- **Reaches for** — *recognition* / *judgment* / both.
- **Rating** — the response scale, where the question carries one. Cluster 4's question is open-only and carries none.
- **Field label + open prompt** — the short label on the open-response field, and the prompt text inside it. Cluster 4's open response is required.
- **Supporting material (abstract)** — what the screen's panels must establish, named by affordance. For Cluster 4 this is a *scope panel* and the always-available reference layer; there is no top panel and no rationale unit. Described, not drafted as final copy.
- **Note** — design reasoning, risks, analytical interest.

**Standing rule** (carried from Clusters 1–3): a question that asks a practitioner to judge a deliberate design choice without the supporting material carrying the *why* does not test the choice. Cluster 4 triggers it nowhere — the catch-all asks the respondent to raise their own agenda, not to judge a thesis choice, so it carries no rationale unit.

## Cluster 4 supporting material — the introductory grounding

Cluster 4's introductory grounding is the lightest of the four, and deliberately so. It is not building a problem space, re-presenting the framework, or orienting the respondent to a set of objects — the respondent has now crossed the whole framework. Its job is a short close-and-invite: it signals that the structured questions are done and that the final question is theirs to use however they wish. It does not re-summarise the framework or the prior clusters; the respondent has just been through all of it.

**What the Cluster 4 introductory grounding must establish** — described in abstract:

- **The questionnaire is nearly complete.** A plain signal that the structured questions are behind the respondent and one open question remains.
- **What the final question is for.** That it is deliberately unbounded — the one place the respondent, not the instrument, sets what gets raised — and that there is no wrong thing to put there.
- **What "everything you've seen" refers to.** A one-line recall anchor: the problem the framework addresses (Cluster 1), the framework's design (Cluster 2), its instruments (Cluster 3) — so the final question's scope note lands on a concrete referent without re-presenting any of it.

**No neutral-presentation constraint.** Unlike Clusters 1–3, Cluster 4's grounding presents no object for judgment — only an invitation — so it carries no neutral-presentation constraint of the kind the prior clusters needed.

## Q4.1 — The catch-all

**Question.**
> Is there anything important the questions haven't reached?

**Subtitle (scope note).**
> *Look back over the whole questionnaire — the problem the framework addresses, its design, and its four instruments. This last question is deliberately unbounded: the one place where what gets raised is yours to set, not the questionnaire's.*

**Type:** `open-only`
**Reaches for:** both — recognition and judgment.

**Rating:** none — this is an `open-only` item.

**Field label:** Anything to add
**Open prompt (required):** *Whatever you'd raise — a concern, a gap, a strength the earlier questions passed over, a question they should have asked. If they covered the ground for you, saying so is a complete answer.*

**Supporting material (abstract):** no top panel and no source-material panel — this screen presents no object, only an invitation. A **scope panel** doing two things: establishing that the question is genuinely unbounded (any concern, gap, strength, or question the structured items should have asked is in scope), and establishing that a brief answer — or one saying the earlier questions covered the ground — is a complete answer, so a respondent who feels the structured questions did their work is not pushed to manufacture a critique to satisfy the required field. The reference layer stays available throughout (F3), so a respondent who wants to revisit any part of the framework before answering can. No detailed-explanation card; no rationale unit.

**Note.** The questionnaire's final item — deliberately open-only and deliberately unstructured, the one screen where the respondent sets the agenda rather than answering to the thesis's claim spine. It is the lightest open-only item in the instrument: no object to judge, no design choice to assess, which is why ending on an obligatory open response is the right close rather than a heavy one. It is obligatory (F6) because a structured questionnaire that makes its catch-all optional tends to collect nothing in it; requiring an answer, while accepting "nothing to add" as a legitimate one, is what makes the item produce data without forcing noise. For Chapter 9 it does two things: it surfaces concerns the four-construct, four-instrument structure had no slot for, and — across the sample — a pattern in what respondents independently raise is itself a finding about what the questionnaire's structure left out. Whether a second, fully optional instrument-feedback catch-all joins it is the cluster's one open decision; it is in the notes below, not pre-empted here.

## Cluster 4 — notes for the discussion

- **One question, by design.** Cluster 4 is the lightest cluster — the closing cluster's job was always lighter than the other three, and a single well-placed catch-all does it. An earlier draft carried a second question on self-limitation (C5'); it was dropped to interview (below).
- **C5' dropped to interview; not replaced.** A generic "rate the whole framework" rating was considered as a replacement and rejected: that is precisely the satisfaction-style framework-quality item the whole instrument is built to avoid (the DGSB / Durkiewicz comparator lesson; ADR §8; construct memo §1), and it would add nothing Chapter 9 can use. The clean decision is to drop Q4.1's predecessor and not replace it. The consequence — C5' probed nowhere in the questionnaire — is consistent with the construct memo §3.1 and is flagged in the orientation for Chapter 9's dual-framing to account for.
- **The catch-all is obligatory but accepts "nothing to add."** Required as an item (F6) so it produces data, but the scope panel and the open prompt both make clear that a brief answer, or one saying the structured questions covered the ground, is legitimate — a respondent who genuinely feels the questions did their work should not be pushed to manufacture a concern.
- **No coined terminology in the stem, subtitle, or prompt.** Cluster 4 holds the register Clusters 1–3 hold: thesis vocabulary stays in the supporting-material panels, the reading path stays plain. The reading path here is the plainest in the instrument — there is no construct name, no instrument name, and no rating label to keep clean.
- **Open decision for the review round: a second, fully optional instrument-feedback catch-all.** An item along the lines of "anything about the validation exercise itself — the platform, the questions, the experience — you'd want to flag." The construct memo's "one or two final open items" allows it; it would collect platform- and instrument-improvement feedback without pretending to be validation data; it is fully optional, so it adds no required-response load. It is not in the current draft. The recommendation on record is to add it; the decision is surfaced here, not pre-empted. If it is added, it becomes Q4.2 and the cluster runs either two screens or one two-question screen — itself a small layout decision for the same review round.
- **Cross-cluster consolidation is the next step, not a Cluster 4 task.** With all four clusters now drafted and consolidated, the questionnaire needs an end-to-end pass: the cluster-to-cluster arc and handoffs (including the soft Cluster 1→2 hinge), redundancy across clusters, total respondent time against the 75–90 minute budget, and the open-response-weight balance now that Cluster 3 runs on a rating spine. That pass is its own piece of work.
