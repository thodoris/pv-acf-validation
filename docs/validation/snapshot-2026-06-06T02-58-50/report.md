### Statistic conventions

- **Frequency tables** list every option the question defines, including zero-count options.
- **Median** is the lower-middle response when N is even (no interpolation — rating scales are non-uniform 4–6-point ordinals).
- **Mode** lists every option tied for the highest count, joined by ` / `.
- **Mean & SD** treat the option index (1-based) as an interval variable. This is conventional in validation reporting but ordinal-purists may prefer to quote the median and frequency table only.
- **Non-substantive options** ("Cannot judge", "Not familiar enough to say", "…not yet in place") are kept at their scale position in the figures; their combined rate is reported per item as a no-opinion / not-applicable line so the reader can judge each item's interpretability.
- **Open-response** sections report only N + word/character counts. Verbatim text is never written to this report; pass `--include-opens` if you need the corpus as a side-file.
